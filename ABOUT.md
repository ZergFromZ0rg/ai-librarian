# AI Librarian

AI Librarian is a self-hosted, local-first knowledge library for PDFs and
common office documents. It watches chosen folders, preserves the original
files, extracts searchable structure, and combines semantic and keyword search
with grounded answers that cite their source pages.

The project is designed for private libraries: indexing, retrieval, and the
default model workflow can run on the reader's own server, with optional cloud
providers available when explicitly configured.
